# Resume Application Copilot

一个隐私优先的 Chrome / Edge 求职申请自动填充扩展。它把简历和其他材料整理成可复核的个人资料库，然后在你自己打开的招聘页面中识别字段、展示匹配结果，并在你确认后填写。

扩展不会自动寻找职位、点击下一步、绕过验证码、批量投递或点击最终提交。

## 目录

- `extension/`：Chrome/Edge Manifest V3 扩展源码
- `release/`：可分发的扩展安装 ZIP
- `demo/`：本地模拟招聘表单和虚拟示例材料
- `skill/`：可选的 Codex Skill
- `tests/`：JavaScript 和 Python 测试

## 安装扩展

### 方式一：加载源码目录（开发和验证推荐）

1. 下载或克隆本项目。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择项目中的 `extension/` 文件夹。

### 方式二：使用发布 ZIP

解压 `release/resume-application-copilot-v0.3.1.zip`，然后在扩展管理页选择解压后的 `extension/` 文件夹。浏览器扩展不能直接从 ZIP 中加载。

代码更新后必须在扩展管理页点击“重新加载”；如果浏览器仍显示旧图标或旧界面，关闭并重新打开侧边栏。

## 完整 workflow

### 第一步：建立个人资料库

1. 点击扩展图标，打开“设置/个人资料库”。
2. 填写基础信息、联系方式、教育经历、实习/工作经历、项目经历、学生干部经历、志愿经历、证书、技能和常见问答。
3. 在页面顶部的“导入材料与解析记录”中选择 PDF、DOCX、TXT、JSON 或图片。
4. PDF 和 DOCX 会在本地解析；解析出的原文和候选字段会显示在页面中。
5. 检查候选字段，点击“应用已选候选”。低置信度和敏感候选不会被盲目应用。
6. 检查个人资料表单，点击“加密保存资料”。

资料库包含身份证号、家庭信息、紧急联系人等敏感内容时，也会和普通资料一起保存在本地加密资料库中。敏感内容不会因为保存而自动填写或发送给 AI。

首次保存后可以勾选“在本机自动解锁”。之后在同一个浏览器配置中重新打开设置页或侧边栏，不需要重复输入主密码。浏览器只保存本机不可导出的加密密钥，不保存主密码。

### 第二步：打开招聘页面

1. 由用户自己打开招聘或报名官网页面。
2. 点击扩展图标打开侧边栏。
3. 第一次访问某个网站时，浏览器可能会询问是否允许扩展读取当前网站；只在你确认需要填充时允许。
4. 点击“解锁并扫描当前页面”。开启本机自动解锁后，主密码可以留空。

扩展只在你点击扫描后读取当前页面，不会后台扫描所有网站。

### 第三步：审核字段匹配

侧边栏会展示：

- 页面字段名称
- 对应的个人资料路径
- 来源材料
- 匹配置信度
- 是否为敏感字段

例如：

```text
性别       → 女
最高学历   → 本科
专业       → 应用经济学
GPA        → 3.7/4.0
专业排名   → 5/100
```

### 第四步：确认填充

点击“确认填充已选字段”后，扩展可以处理：

- 文本框和文本域
- 日期字段
- 原生 `<select>` 下拉框
- 常见自定义下拉框和 combobox
- 单选框和复选框

扩展会根据选项文字选择“男/女”“本科/硕士”“Male/Female”等对应选项。自定义下拉框会先展开，再点击匹配的可见选项。

低置信度字段只作为候选展示；敏感字段仍需人工确认。扩展不会点击“下一步”“提交”“验证码”或其他最终动作。

## PDF 和材料解析

文字型 PDF 使用扩展内置的 PDF.js 在本地提取文字，并解析：

- 基础信息
- 教育经历、院系、专业、学历、时间、GPA、排名和课程
- 实习/工作经历
- 项目经历
- 学生干部和校园经历
- 志愿与社会实践
- 证书、竞赛和荣誉
- 技能、语言和求职偏好
- 常见申请问答

扫描件或图片型 PDF 如果提取出 `0` 个字符，需要先使用 OCR。扩展不会扫描电脑中的其他文件，只读取你主动选择的材料。

## 本地模拟验证

项目中的 `demo/` 用于不访问真实招聘网站的测试。可以用浏览器打开其中的本地测试页面，然后按“扫描 → 审核 → 确认填充”验证流程。

## 导出 JSON 是什么

“导出 JSON 备份”用于备份或迁移个人资料库，不是日常填充必须步骤。导出的 JSON 是未加密文本，可能包含身份证号、家庭信息、API Key 等敏感内容，只应保存在安全位置，不能上传到 GitHub 或发送给他人。

## 开发验证

```bash
npm test
python -m unittest discover -s tests -p "test_*.py"
```

当前版本的 JavaScript 和 Python 测试均应通过。修改扩展源码后，重新执行测试并在 `edge://extensions` 或 `chrome://extensions` 中重新加载扩展。

## 隐私与安全边界

- 个人资料、导入原文、解析候选、敏感字段和 API Key 默认只保存在浏览器本地。
- 普通资料和敏感资料都使用 AES-GCM 加密保存。
- AI 请求只发送生成答案所需的非敏感资料；身份证、银行卡和家庭信息不会自动发送。
- 所有填充都需要用户主动点击确认。
- 不实现自动提交、批量投递、验证码绕过或后台读取所有网站。
